# PeerPod Frontend Docs

This folder keeps the frontend repo self-explanatory, even though the backend lives in a separate repository.

## Docs in this folder

- [Overview](./OVERVIEW.md): product context, backend relationship, and frontend mission
- [Frontend Architecture](./FRONTEND_ARCHITECTURE.md): structure, state flow, API usage, and realtime behavior
- [Implementation Notes](./IMPLEMENTATION_NOTES.md): current status, what is built, and next intended steps

## Source of truth relationship

- `peerpod-frontend` is the UI repo
- `PeerPod` is the backend repo

This docs folder mirrors the important context the frontend needs so work can continue from here without constantly switching back to the backend repo.
